One razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting — an entry for [The Funniest Excuse for Skipping a Meeting](https://make.fun/c/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) on [make.fun](https://make.fun).

## The entry

> I'm at the printer. It's printing someone's resignation and I need to know how it ends.

## How it works

`main.py` writes the entry line to `/output/entry.txt`. That's it — one line, no dependencies, no network.

```sh
python3 main.py
cat /output/entry.txt
```
